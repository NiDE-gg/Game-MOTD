    Zombie Escape Rules 

     Gameplay :

    • Inflating or Teamwork between human and zombies is prohibited, any attempt will result in a warn, a kick or a ban.
    • Griefing in any way (knifing, shooting or pushing zombie forward) is prohibited, any attempt will result in Kban ⁽¹⁾.
    • Re-joining the server as the only zombie alive will result in a ban.
       

     Map Items :

    • If you do not cooperate with the team while having an item it may be transferred without warning.
    • Teamkilling or ruining others players experience on purpose with an item can lead to an Eban ⁽²⁾.
    • Picking up items only to throw them away or intentionally misusing it will lead to an Eban ⁽²⁾.
       

     Communications :
